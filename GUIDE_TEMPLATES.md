## Guide structure templates

Three guide structures have shipped. They serve different bank shapes; a fourth subject's guide should pick from these (or pivot again) by analysing the bank first, not by copying precedent.

### Template A — principles-first (NDA Maths)

Use when the bank has **cross-chapter levers** (one principle spans ≥4 chapters) and **non-flat %HARD** (multiple chapters > 20% HARD).

- **Routes:** landing + `/strategy` (Tier A/B/Skip) + `/principles` (catalog) + `/principles/[slug]` (deep dives) + `/compound-tricks` + `/trends` + `/traps`.
- **Tag infra:** DB-backed `question_<X>_tags` table (today: `question_principle_tags`, migration 0023). Hand-curated TOP_N; counts + %HARD + chapter spread computed live from the tag table at request time.
- **Strategy axis:** %HARD-driven tiering. Chapters with high q-count AND low %HARD = Tier A; high q-count + high %HARD with one drillable subtopic = Tier B cherry-pick; everything else = skip.
- **Editorial data shape:** `OVERVIEW + CHAPTER_TABLE + TIER_A/B + SKIP_LIST + TOP_11 principles + DOMAINS long-tail + COMPOUNDS + DRIFT_ROWS + TRAPS + per-principle DETAILS`.

### Template B — playbooks-first (NDA English, NDA Chemistry, NDA Biology, NDA Geography, NDA History)

Use when the bank has **sealed chapters** (largest cross-chapter lever < ~30 q). Pure Template B also requires **flat %HARD** (≤2 chapters > 15%); the Geography variant relaxes that gate (see "B + non-flat %HARD" below).

- **Routes:** landing + `/strategy` (skill buckets, not tiers) + `/playbooks` (catalog) + `/playbooks/[slug]` (deep dives — one per major subtopic OR one per chapter — see variants below) + `/<subject-specific-page>` (e.g. `/vocab-families` for English, `/common-compounds` for Chemistry) + `/trends` + `/traps`.
- **Tag infra:** NONE. Cross-chapter horizontal axis is too thin to justify a DB table. Drill CTAs use `subtopicIds` or `chapterIds` from `resolveTaxonomy` at request time — same machinery as the maths long-tail DOMAINS principles.
- **Strategy axis:** Skill-type buckets, not %HARD tiers. The middle bucket is the variable slot — pick it from the subject's natural seams:
  - **English** uses Recall (Vocab + Idioms — memorisation) / **Rule** (Errors + Grammar — rule application) / **Reason** (RC + Cloze + Rearrangement + FIB — context-driven).
  - **Chemistry** uses Recall (Carbon + Matter + Industrial + Metals + Hydrogen + Everyday Life + Practical — fact recall) / **Rule** (Atomic Structure + Acids/Bases + Reactions + Bonding — rule application) / **Calculate** (Mole Concept — small numeric strand). Chemistry has no chain-reasoning lever (no analogue of RC author-stance) but does have a small but distinct numeric strand worth surfacing as its own bucket.
  - **Biology** uses Recall (Human Physiology + Cell Biology + Microbiology + Biodiversity + Genetics — named-fact recall) / **Apply** (Plant Biology + Reproduction — mechanism-tracing: photosynthesis flow, osmosis direction, inheritance ratios, pollination genetics) / **Verify** (Ecology + Biochemistry — multi-statement true/false evaluation, the bank's second-largest question shape at ~24 q). Biology has NO numeric strand (no analogue of Mole), no Rule-application lever beyond pattern-application (which collapses into Recall in practice), and only 4 chain-reasoning HARDs across 190 q — too thin for a Reason strand. The **third slot bent to Verify** to capture the dominant non-recall execution mode; the **second slot bent to Apply** to surface the mechanism-tracing chapters that carry 4 of the bank's 5 HARDs. So Biology's Recall + Apply + Verify split is unique even within Template B — the Rule slot itself bent.
  - **Geography** uses Recall (Indian Geography Economy + Indian Geography Physical + World/Human — named-fact recall: rivers/peaks/states/crops/minerals/ports) / **Apply** (Climatology + Earth's Structure — mechanism-tracing: cyclogenesis, plate tectonics, weathering, rock-cycle classification) / **Verify** (Earth in Space + Oceanography — multi-statement evaluation: "consider the following statements about terrestrial planets / cold ocean currents"). Same Recall/Apply/Verify split shape as Biology; the unique twist is that Geography has **non-flat %HARD** (4 of 7 chapters >15% HARD) — see "B + non-flat %HARD" below for the variant pattern. Initial guess was a Map/Concept/Current-Events split (in the deprecated "other subjects may need different splits" prose); SQL analysis showed Recall/Apply/Verify fits better because Geography's multi-statement shape (92 q) dominates the non-recall execution mode.
  - Current Affairs (not yet a guide) might still need a different split — one-bucket-many-themes. The Recall slot is universally stable; the OTHER TWO slots bend to the subject's natural seams.
- **Playbook granularity:** English uses per-subtopic playbooks (chapters are skill buckets, each subtopic is a distinct question type — 16 playbooks across 8 chapters). Chemistry uses per-chapter playbooks (subtopics well-cleaned but thin at 2–5 q each — 12 playbooks 1:1 with chapters, same rationale as physics). Biology uses per-chapter playbooks too (9 playbooks 1:1 with chapters; subtopics thin, max 13 q on HP.Circulatory + MD.Pathogens). Geography uses per-chapter playbooks too (7 playbooks 1:1 with chapters; subtopics avg ~5 q, max 36 q on Agriculture). Pick based on whether subtopics are large enough to anchor a standalone deep-dive.
- **Subject-specific page:** Required for Template B in practice. English's `/vocab-families` (13 themed word clusters); Chemistry's `/common-compounds` (6 themed name↔formula↔use clusters, ~50 compounds, rendered via the new `CommonCompoundsTable` component); Biology's `/reference-tables` (4 themed clusters, ~52 named-fact pairs — rendered via the generic **multi-domain** `ReferenceTables` component: each cluster carries its own column headers); Geography's `/reference-tables` (4 themed clusters, 62 named-fact pairs — Indian Rivers / Mountain Peaks / Mineral & Crop Producer States / Local Winds + Climate Zones — same generic `ReferenceTables` component). All four follow the same recall-anchor pattern — a flat-list reference the recall strand drills against.
- **Editorial data shape:** `OVERVIEW + CHAPTER_TABLE + STRATEGY_BUCKETS + PLAYBOOKS + per-playbook DETAILS + <subject-specific clusters/families> + DRIFT_ROWS + TRAP_SHAPES`.

**The strand-axis lesson (updated by Biology + Geography + History):** ONLY the Recall slot is universally stable across Template B subjects — and even that can manifest as one strand (Recall) or part of a larger Foundation Recall tier. The SECOND slot is usually Rule but can bend to Apply (Biology + Geography mechanism-tracing) or — when even execution-mode is uniform across chapters — to TIER (Cornerstone for History's dominant Modern India). The THIRD slot is the most variable — Reason (English chain-context), Calculate (Chemistry numeric Mole strand), Verify (Biology + Geography multi-statement evaluation), Quick-Win (History's low-%HARD World History). Picking the strand axis itself (execution mode vs strategic tier) is the highest-leverage decision in a new Template B guide. **History was the first subject where execution-mode strands failed** — multi-statement and date-anchored modes are uniform across all 4 chapters, so they couldn't partition. Tier-style strands (Cornerstone / Foundation Recall / Quick-Win) were the fallback.

#### Template B variants — strand-axis fork (execution-mode vs tier-style)

| Strand axis | Subjects | When to pick | Examples |
|---|---|---|---|
| **Execution-mode strands** | English, Chemistry, Biology, Geography | When execution modes (Recall/Rule/Reason etc.) partition chapters into recognisable clusters — each chapter has a DOMINANT execution mode that distinguishes it from others. | English: Vocab/Idioms = Recall vs RC/Cloze = Reason. Bio: HP/Cell = Recall vs Plant/Reproduction mechanism-tracing = Apply. |
| **Tier-style strands** | History, Polity | When execution modes are bank-wide-UNIFORM (cut across all chapters at similar %), OR the bank is too small + chapter count too low for skill-bucket labels to be more actionable than strategic-priority labels. | History: multi-statement 70 q × 4 ch + date-anchored 61 q × 4 ch are uniform — but Modern India is 47% of bank (vs next chapter 20%), creating a Cornerstone/Foundation/Quick-Win priority axis. Polity: only 90 q · 4 ch · avg 5 q/paper (smallest GAT section); multi-statement partition is partial (4.5–50% across 4 chapters); strategic-priority labels name-drop each chapter directly. |

**Decision probe:** For each candidate execution mode, count `q × chapter_spread` AND look at the per-chapter distribution. If the top mode is 60%+ of one chapter and 20%- of others, execution-mode strands work. If it's 25–45% of every chapter, modes are uniform → fall back to tier-style. **Also drop to tier-style** when the bank is small enough (≤100 q · ≤4 ch) that strategic-priority labels are more actionable than execution-mode labels at this scale — Polity's call.

**Tier-style third-tier inversion** (History vs Polity): tier-style strands have a stable Cornerstone (dominant chapter) + Foundation Recall (recall-heavy mid-chapters) — but the THIRD tier's semantics depend on the smallest chapter's profile. History's World History is small AND easiest (20% HARD, lowest in subject) → **Quick-Win** label. Polity's World Polity is small BUT HARDEST (42% HARD, highest in subject, 50% multi-statement) → **Specialist Wildcard** label (small + high-reward, opposite framing). Don't reach reflexively for "Quick-Win" — verify the third tier's %HARD profile against the rest of the subject first, and relabel when the smallest chapter is the HARDEST.

**The %HARD-handling lesson:** Template B's "flat %HARD" gate is the most easily relaxed prerequisite. When %HARD is non-flat but HARD is **diffuse within chapters**, stay in Template B and switch from "no HARD signal" to "strand-level HARD calibration" — don't escalate to Template C. The escalation to C only earns its place when HARD pools are concentrated enough that "drill all EASY subs, skip the HARD ones" is a meaningful piece of strategy.

### Template C — chapter-playbooks + skill-strand + formula compendium (NDA Physics, MHT-CET Maths)

Use when **neither A nor B fits cleanly**: cross-chapter lever too thin for principles (max < ~30 q × ≥4 ch — fails A's gate) AND %HARD is mid-spread (3–6 chapters > 15% HARD — too non-flat for B's strategy to capture). NDA Physics: max cross-chapter lever 12 q × 6 ch; 5 of 14 chapters > 15% HARD with HARD concentrated in 1–2 specific subtopics per chapter (Resistance & Circuits 42%, Calorimetry 31%, Thermo Processes 33%, Buoyancy 31%, etc.).

- **Routes:** landing + `/strategy` (skill strands with %HARD-aware DrillPosture overlay) + `/playbooks` (catalog) + `/playbooks/[slug]` (deep dives — **one per chapter**, not per subtopic; physics chapters ARE the natural unit, subtopics too fine at 1–3 q each) + `/formulas` (single-page compendium — NEW page kind) + `/trends` + `/traps`.
- **Tag infra:** NONE (same rationale as B). Per-playbook drills use `chapterIds` + optional `subtopicIds` from `resolveTaxonomy` at request time.
- **Strategy axis:** Skill strand (Recall / Apply / Reason) PLUS per-chapter `DrillPosture` ∈ {drill-all, drill-all-target-hard, cherry-pick-easy-mod, skim}. The posture answers the question B can't: "drill every subtopic of this chapter, or cherry-pick the EASY/MOD subtopics and skip the HARD ones?" — necessary when 5 chapters carry real HARD load.
- **Editorial data shape:** `OVERVIEW + CHAPTER_TABLE + STRATEGY_STRANDS + (per strand) StrandChapter[] with DrillPosture + targetHard + skipSubtopics + PLAYBOOKS (1 per chapter) + per-playbook DETAILS + FORMULA_GROUPS (chapter-grouped) + DRIFT_ROWS + HARD_BY_YEAR + DRIFT_CALLOUTS + TRAP_SHAPES (by strand)`.
- **New components:** `FormulaSheet` (chapter-grouped formula renderer — plain-text + unicode, no KaTeX pipeline → page stays server component). Related-playbooks use the generic `RelatedPlaybooks` component (`guidePath="nda-physics"`).

#### Template C variant — tier-style strands for a NO-NEGATIVE-MARKING exam (MHT-CET Mathematics, 2026-08-22)

The first non-NDA guide, and it bends Template C in one place that generalises to every future exam: **the MARKING SCHEME chooses the strategy AXIS, not just the numbers on the page.**

- **The axis rule.** Every NDA guide's `/strategy` is organised around *attempt vs skip*, because NDA deducts 1/3 for a wrong answer. **MHT-CET deducts nothing**, so a blank and a wrong answer score identically, `targetAttempts === paperQ` by construction, and any copy reading as "skip" is actively wrong advice. The axis becomes **ORDER and TIME** (50 q × 2 marks in 90 min = 1.8 min/question). `skipSubtopics` still exists in the data but is rendered as *"Last in the prep queue"* — a prep-order call, never a paper-day one — and the strike-through styling NDA uses was deliberately dropped. **Before writing any strategy page, look up the exam's marking scheme; it is not a detail, it is the axis.**
- **Strand axis: tier-style, and it was forced by measurement.** Execution-mode strands (Template B's default, step 5) are DEAD for CET Maths: probing four candidate modes per chapter shows them uniform (evaluate 10–40%, solve-for-parameter 20–40% nearly everywhere) with exactly ONE outlier — Mathematical Logic at 70% "which statement is true" against ~0% elsewhere. Tiers are `cornerstone` / `quickwin` / `longtail`, sized 6 / 5 / 11.
- **Tier on RECENT weightage, never lifetime, when the syllabus can move.** MHT-CET shifted for 2025: Measures of Dispersion ran 1.0 q/paper across 29 shifts of 2023-24 then scored **zero across all 14 papers of 2025**, while Conic Sections went 3 → 16. At 9% HARD, Dispersion is exactly what a lifetime-tiered guide recommends as a cheap win — and it is dead. **A lifetime average hides both directions of a syllabus move.** Watch the denominator too: computing a per-chapter rate over only the years where that chapter appears makes a dead chapter read as a live 1.00/paper.
- **Playbook inclusion line rather than one-per-chapter.** 27 chapters, but playbooks ship only for the 22 at ≥0.9 q/paper; the 5 below are named in a tail block on `/strategy` so the bank is accounted for rather than quietly truncated. NDA Physics ships one per chapter because it has 14; past ~20 chapters an explicit, stated line beats padding.
- **The principles axis was surveyed and rejected on evidence.** A keyword scan showed 8 candidates clearing A's gate; reading the questions killed three of them (see [[principle-tag-survey-methodology]] for the two rules that did it) and left 5 — thin against A's precedent of 12. **Run the survey before choosing A, and read questions before trusting the count.**
- **Routes:** landing + `/strategy` + `/playbooks` + `/playbooks/[slug]` + `/formulas` + `/trends` + `/traps`. **No `/ncert-map`** — MHT-CET is set on the Maharashtra State Board syllabus, not NCERT.
- **`DriftTable` does NOT fit a multi-shift exam.** It takes a flat `counts: Record<year, number>`, and raw counts are meaningless when 2021 is 1 shift and 2023 is 17. CET's `DriftRow` carries two self-describing windows with per-paper RATES instead, and the trends page renders its own list. Only ship drift rows you can evidence — a fabricated 27×5 grid reads as measured in every cell.
- **`FormulaSheet` is now parameterised** (`groups`, `guideSlug`), defaulting to NDA Physics so its call site is unchanged. Formulas stay **plain-text + unicode, not LaTeX** — the component renders `{f.formula}` as raw text, so LaTeX ships literal `\frac{...}` onto the page.
- **Shipping a second exam's guides made `/guide` a real exam picker** (registry-derived from `EXAM_REGISTRY.guidesPath`), and gave `/guide`, `/guide/nda` and `/guide/mht-cet` the `/notes`-style exam rail via `GuideShell` — those three were the only pages in either tree with no side nav. Rail helper: `src/lib/guide/guidesNav.ts`. Cost: `/guide/nda` dropped from a 4-col to a 2-col card grid, because the rail takes 16rem and `GuideShell` caps content at `max-w-3xl`.
- **Guides have NO registry, unlike notes.** `/notes` derives its hubs from `NOTES_CHAPTERS`, so a new exam's notes hub is free; each guide hub hardcodes its subject list, which is why MHT-CET needed a hand-written `/guide/mht-cet` page. `guidesNav.ts` models the exam level only. Build the missing subject-level registry before a third exam, or hand-write a third hub.
- **A shared invariant asserted from one exam's facts breaks on the first new exam.** `tests/guide-strategy-headline.test.ts` asserted `penaltyPerWrong ≈ marksPerCorrect / 3` for EVERY guide — NDA's scheme as a universal law — which a correct MHT-CET headline fails. It is now per-guide `marking` data. Likewise **three tests used MHT-CET as their exemplar of a guide-less exam**; when a placeholder becomes real, grep for it as a test fixture.

### Single-page landing (NDA Economics)

Use when the bank is **too thin for any multi-route template** to produce a non-parody strategy. NDA Economics: 24 q · 1 chapter · 3 subtopics · 1.5 q/paper · ~6 marks/paper max — Template A impossible (1 chapter rules out cross-chapter levers), Template B/C `STRATEGY_HEADLINE` reads as parody ("attempt 1.5 of 1.5, target 4 of 6"). Deliberately thinner terminal node, not a fourth template variant.

- **Routes:** landing only. No `/strategy`, no `/playbooks`, no `/trends`, no `/traps`, no `/principles`, no `/reference-tables`, no per-playbook detail pages.
- **Tag infra:** NONE. Cross-chapter axis impossible at 1 chapter.
- **Strategy stance:** named in prose, not in a `STRATEGY_HEADLINE` constant. Cap the subject explicitly ("~6 marks of 600-mark GAT, ~1%"), tell the reader what to do (drill the bank, internalise the one recall anchor, accept the cap), and link out.
- **Editorial data shape:** `OVERVIEW + SUBTOPIC_TABLE + <single-domain recall anchor>` (e.g. `FIVE_YEAR_PLANS` for Economics) `+ POST_PLAN_NOTE` or analogue. No `CHAPTER_TABLE` — 1 chapter doesn't warrant a table.
- **New components:** NONE. The subject's recall anchor renders as an inline `<table>` on the landing — simpler than `CommonCompoundsTable` because there's no per-cluster sub-grouping.
- **Sitemap priority 0.7** (vs 0.8 for full landings) — flags the thinness for crawlers.
- **`questionResources.ts` maps the subject's chapter to the landing** (Template A pattern — single landing, label `"NDA <subject> strategy"`) so `/browse` cards still get a backlink chip.

The bank-thinness gate is the entry point — see "Choosing the template" step 0.

### Template D — theme-prep checklist for short-half-life subjects (NDA Current Affairs)

Use when the bank's CONTENT goes stale (specific facts rarely repeat across years) BUT the bank's SHAPES are stable (recurring question types persist even when the specific facts in them rotate). NDA Current Affairs: 180 q · 8 ch · 31 sub · ~10 q/paper · ~40 max marks — multi-route templates would teach students 2017–2025 trivia and call it strategy. Template D is the honest alternative: name the half-life, name the recurring shapes, point at this year's news.

- **The half-life test** (empirical entry criterion): SQL-probe the bank for "year mentioned in question vs paper year". If 80%+ of explicit-year mentions are within 12 months of paper, half-life is short. Cross-check by counting recurrence of named entities (specific exercises / schemes / award winners) across paper-years — if each named entity appears in at most one paper, fact-memorisation has near-zero forward-prep value.
- **The stable-themes counter-test:** before defaulting to no-ship, count subtopics that appear in 5+ years of papers. If ≥6 subtopics meet that threshold and carry ≥40% of bank, the recurring SHAPES are stable enough to anchor a guide even when the FACTS aren't.
- **Strand axis = recurrence strength** (NEW — not skill, not strategic priority): Anchor themes (5+ year recurrence) → Recurring themes (3–4 year recurrence) → Occasional themes (1–2 year recurrence). Strand sizes are uneven by design; the prep-investment asymmetry is the point.
- **Theme cards** (the load-bearing artefact) — each anchor theme card carries: (a) **question SHAPE** — one sentence describing the recurring stem pattern, sourced from real bank stems (durable); (b) **prep CHECKLIST** — 3–6 fact-CATEGORIES to harvest from this year's news (durable directives, the student fills in this year's specific facts from an external compendium); (c) optional **durable-anchors** callout — the small subset of structural facts that genuinely don't rotate (G7 nations, UN agency HQs, ISRO launch-vehicle classes, etc.); (d) **drill BrowseLink** — practises the SHAPE against the bank's historical instances, NOT the facts.
- **Routes:** landing ONLY. No /strategy, no /playbooks, no /trends, no /traps, no /reference-tables, no per-playbook detail pages. Every section lives on the single page, ordered: hero + half-life directive + chapter table + anchor theme cards + recurring themes table + occasional themes chips + test-day plan + drill CTAs + closing rationale.
- **Tag infra:** NONE. Cross-chapter axis impossible — each chapter is a different subject domain (Defence ≠ Sports ≠ Awards). No `question_<X>_tags` table.
- **New components:** NONE. Anchor theme cards render as inline JSX `<article>` (same pattern as nda-economics's inline FYP `<table>`).
- **Editorial data shape:** `OVERVIEW + CHAPTER_TABLE + ANCHOR_THEMES (8 entries with shape + checklist + durableAnchors? + drillSubtopics) + RECURRING_THEMES (16 entries with oneLineShape + drillSubtopics) + OCCASIONAL_THEMES (7 entries minimal) + HALF_LIFE_NOTICE + TEST_DAY_PLAN`.
- **STRATEGY_HEADLINE stance:** named in the TEST_DAY_PLAN block, not in a copy-pasted constant. CA per-paper count is ~10 q (range 6–14), so ~40 max marks and target ~24 marks at 80% on 7 attempts.
- **Sitemap priority 0.6** (vs 0.7 for Economics, 0.8 for full landings) — flags the unusual template shape for crawlers.
- **`questionResources.ts` maps the subject's chapters to the landing** (Template A / single-page pattern — single landing, label `"NDA <subject> strategy"`).
- **Honest framing in copy is non-negotiable** — the half-life directive callout at the top of the page MUST explicitly say "drill this bank for SHAPE, not for FACTS" and point at an external compendium. Without it, students mistake the bank for the prep resource and memorise historical answers. The "Why this guide is one page" closing section names the alternative we didn't ship ("a 5-section guide would teach you 2019 facts and call it strategy").

### Choosing the template — the analysis script

Before proposing a new guide, run this analysis (SQL probes documented in [[english-guide-structure-diverges]] memory):

0. **Bank-thinness gate.** If avg q/paper < 2 OR total bank < ~50 q OR chapters = 1, no Template A/B/C will produce a non-parody `STRATEGY_HEADLINE`. **Ship a single-page landing instead** (see "Single-page landing" section above). NDA Economics (24 q · 1 ch · 1.5 q/paper · ~6 max marks) is the precedent; NDA Polity (90 q · 4 ch · 5 q/paper · 20 max marks) is the smallest *multi-route* guide and clears the floor. Below that floor, multi-route padding hurts more than it helps.
0a. **Content half-life gate** (run AFTER the thinness gate clears). SQL-probe `regexp_matches(text, '(20[12][0-9])', 'g')` against the bank and compute `(year_mentioned - paper_year)`. If 80%+ of explicit-year mentions are within 12 months of paper AND specific named entities (exercises / schemes / awards) almost never recur across paper-years, the content half-life is too short for a multi-route fact-memorise guide. Counter-test: if ≥6 subtopics appear in 5+ years (stable SHAPES even when FACTS rotate), **ship Template D — Theme-Prep Checklist** (see section above). NDA Current Affairs (180 q · 8 ch · 10 q/paper · 90% within-12-months mention rate · ~zero entity recurrence · 8 anchor themes at 5+ year recurrence) is the precedent.
1. **Chapter mix + %HARD per chapter.** Count chapters at each %HARD tier (>15%, >20%, >25%). Helps separate flat (Template B) from non-flat (A or C).
2. **Cross-chapter principle candidates.** Run keyword surveys for plausible horizontal levers. If the top candidate spans ≥4 chapters AND ≥40 q, **principles axis lives — Template A**. If it spans <4 chapters AND <30 q, **principles axis dead — go to step 3**.
3. **Pick B vs C by %HARD spread + concentration.** Three branches:
   - **≤2 chapters > 15% HARD** → flat — **pure Template B** (English / Chemistry / Biology shapes).
   - **3+ chapters > 15% HARD AND HARD is concentrated in 1–2 subtopics per chapter** (cherry-pick pattern lives) → **Template C** (chapter-playbooks + skill-strand + per-chapter DrillPosture overlay + flat-list page like formulas).
   - **3+ chapters > 15% HARD BUT HARD is diffuse within chapters OR concentrated-but-immovable** (no clean cherry-pick) → **Template B + non-flat %HARD variant** (Geography shape — Template B routes/granularity/subject-specific page, but strand-level %HARD calibration in place of DrillPosture).
4. **Subject-specific page.** Most guides have one (vocab-families for English, formulas for Physics, common-compounds for Chemistry, reference-tables for Biology + Geography, timeline-and-pairs for History). If the subject has a flat-list artefact that doesn't fit a playbook (formula sheet, periodic table chunk, named-acts list, name↔formula reference, named-fact pair table, named-place reference, chronology timeline), it's a candidate. Single-domain artefacts → `CommonCompoundsTable`; multi-domain artefacts → the generic `ReferenceTables` component (pass `clusters` + `guidePath`; per-cluster column headers).
5. **Strand axis — execution-mode vs tier-style.** First test EXECUTION-MODE strands (Template B default, what English/Chem/Bio/Geo do). For each candidate mode (recall / rule / apply / verify / calculate / reason / multi-statement / date-anchored), measure `q × chapter_spread` AND the per-chapter distribution. If a mode dominates ONE chapter cluster (60%+ of one chapter, 20%- of others), execution-mode strands work. If modes are roughly uniform across all chapters (25–45% of every chapter), execution mode CAN'T partition → fall back to **TIER-STYLE strands** (Cornerstone / Foundation Recall / Quick-Win — History's pattern). For execution-mode strands, the Recall slot is universally stable. The SECOND slot is usually Rule but can bend to Apply (Bio + Geo) when no rule-application lever exists. The THIRD slot is most variable — Reason (English), Calculate (Chem Mole), Verify (Bio + Geo multi-statement). For tier-style, the slot semantics are different: Cornerstone = dominant chapter, Foundation Recall = recall-heavy mid-chapters, Quick-Win = low-%HARD / smallest chapter.
6. **Subject's natural seams.** If steps 0–5 don't fit (i.e. bank clears the thinness gate but none of A / B-pure / B-variants / C match), propose a new template (and write a memory documenting it).

See `feedback_english_guide_structure_diverges.md` memory for the full "trust the bank's shape" rationale + the 2026-05-18 ship analyses that produced Template B (English), Template C (Physics), Template B variants (Chemistry with Recall/Rule/Calculate + `/common-compounds`; Biology with Recall/Apply/Verify + `/reference-tables`), Template B + non-flat %HARD variant (Geography with Recall/Apply/Verify + strand-level %HARD calibration + `/reference-tables`), and the 2026-05-19 Template B + tier-style strands variants (History with Cornerstone/Foundation Recall/Quick-Win + `/timeline-and-pairs`; Polity with Cornerstone/Foundation Recall/**Specialist Wildcard** + `/reference-tables` — second use of tier-style with the THIRD tier INVERTED because Polity's smallest chapter is the HARDEST, not the easiest).
