**Read the caveats before quoting anything below.**

- **The counts lag.** They are point-in-time notes written at ingest and were already
  inconsistent with one another before this file existed. Run `npm run stats` for live
  figures — never quote this prose.
- **The flags are NOT here.** `practiceOnly` / `boardExam` / `hasMocks` / `mixedFormats`
  change how the site behaves and live in `EXAM_REGISTRY`
  (`src/lib/exam/examContext.ts`), which is the source of truth. The table in
  `CLAUDE.md` mirrors it.
- **The narrative is the value.** What is worth reading here is *how* each corpus was
  built and what went wrong — the defect classes, the source traps, the adjudications.
  Each exam's memory file (`project_*_ingestion.md`) carries the distilled version.
