## Q. 1. (i) — C

Let α = tan⁻¹(1/3), β = tan⁻¹(1/2), both in (0, π/2).

tan(α+β) = (1/3 + 1/2) / (1 − 1/6) = (5/6)/(5/6) = 1, and α+β ∈ (0, π), so α+β = π/4.

Therefore cos(α+β) = cos(π/4) = 1/√2.

**Numeric check (sympy, 30 dp):** value = `0.707106781186547524400844362105`.
Options evaluate to √3/2 = 0.8660254038, 1/2 = 0.5, 1/√2 = **0.7071067812**, π/4 = 0.7853981634.

*Trap noted:* option (D) π/4 is the value of the **sum of the arctangents**, not of its
cosine. It is the designed distractor; the question asks for the cosine.

## Q. 1. (ii) — B

|a·b| = |a||b||cos θ| and |a×b| = |a||b||sin θ|. For non-zero vectors the condition
reduces to |cos θ| = |sin θ|, i.e. |tan θ| = 1. The angle between two vectors is taken
in [0, π], so θ = π/4 or 3π/4.

**Numeric check.** `solveset(|cos θ| − |sin θ|, θ, Interval(0, π))` returned `{0, π/4, 3π/4}`
— note that **0 is spurious**, and I did not take that output as a verdict. A direct
numerical scan settles it:

| θ | \|cos θ\| | \|sin θ\| | difference |
|---|---|---|---|
| 0 | 1.0 | 0.0 | **1.0** (not a solution) |
| π/6 | 0.8660 | 0.5 | 0.3660 |
| π/4 | 0.7071 | 0.7071 | **0.0** |
| π/2 | 0.0 | 1.0 | −1.0 |
| 3π/4 | 0.7071 | 0.7071 | **0.0** |
| π | 1.0 | 0.0 | 1.0 |

So (A) 0 fails (there |a·b| = |a||b| while |a×b| = 0), (C) π/2 fails, (D) fails at both
values. Only (B) holds, and it holds at **both** of its listed values.

## Q. 1. (iii) — D

Direction vectors b₁ = 3î + 2ĵ + 6k̂, b₂ = î + 2ĵ + 2k̂.

- b₁·b₂ = 3 + 4 + 12 = 19
- |b₁| = √(9+4+36) = √49 = 7
- |b₂| = √(1+4+4) = √9 = 3

cos θ = 19/(7·3) = 19/21 ⇒ θ = cos⁻¹(19/21).

**Numeric check (sympy exact):** dot = 19, |b₁| = 7, |b₂| = 3, cos = 19/21 ≈ 0.904762.
The fixed points on the position vectors are irrelevant — the angle depends only on
the direction vectors.

## Q. 1. (iv) — A

For r̄·n̄ = d, the perpendicular distance from the origin is |d|/|n̄|.

|n̄| = √(2² + 3² + (−1)²) = √14, so distance = 5/√14 units ≈ 1.336306.

**Numeric check:** 5/√14 = 5√14/14 = 1.336306210. Option (B) 5/14 = 0.357 and
(D) √14/5 = 0.748 are the reciprocal/mis-rationalised distractors.

## Q. 1. (v) — C

x = e^(x/y) ⇒ log x = x/y ⇒ **y = x / log x** (x > 0, x ≠ 1).

dy/dx = [log x · 1 − x · (1/x)] / (log x)² = (log x − 1)/(log x)².

Now test option (C): (x − y)/(x log x) with y = x/log x:

x − y = x − x/log x = x(log x − 1)/log x, so (x − y)/(x log x) = (log x − 1)/(log x)². ✓

**Numeric check.** First confirmed y = x/log x genuinely satisfies the stem:
`simplify(x − exp(x/y)) = 0`. Then each option minus the true derivative, evaluated at
x = 2, 3, 5, 7.5 (I did **not** rely on `simplify` alone):

| option | `simplify(opt − y')` | numeric differences at x = 2, 3, 5, 7.5 |
|---|---|---|
| A | 1 − 2/log x + 1/log²x | 0.196, 0.0081, 0.143, 0.254 |
| B | 1 + 1/log²x | 3.081, 1.829, 1.386, 1.246 |
| **C** | **0** | **~1e−124, ~4e−124, ~5e−125, 2.8e−17** (all zero to machine precision) |
| D | 2/log²x | 4.163, 1.657, 0.772, 0.493 |

Only (C) is identically the derivative. Option (A) comes close at x = 3 (difference
0.008) but is not zero anywhere else — a nearest-option pick from a single sample
point would have been wrong here.

## Q. 1. (vi) — A

y = c² + c/x ⇒ dy/dx = −c/x² ⇒ **c = −x² (dy/dx)**.

Substituting into (A): x⁴(y′)² − x y′ − y = c² + c/x − (c² + c/x) = 0 for every c and x.

**Numeric/symbolic check** (sympy, with c symbolic — so this is not a one-value fluke):

| option | expression after substitution |
|---|---|
| **A** | **0** (identically) |
| B | c(c x² + c + x)/x² |
| C | c(x(c + 2) + 2)/x |
| D | −4c² − 4c/x + 2c/x² |

Only (A) vanishes identically. Consistent with expectation: the family carries one
arbitrary constant, so the eliminant is a first-order ODE — (C) and (D) are
second-order and cannot be it.

## Q. 1. (vii) — C

For X ~ B(n, p): E(X) = np = 10 × 0.4 = **4**; Var(X) = npq = 10 × 0.4 × 0.6 = **2.4**.

**Numeric check:** E = 4.0, Var = 2.4. The distractor 0.24 is p·q, and 0.4 is p — both
missing the factor n.

## Q. 1. (viii) — D

44°30′ = 44.5° = 45° − 30′ = 45° − 0.5°. Using the given conversion 1° = 0.0175ᶜ
(confirmed on p-03: superscript `c` for radians, prime for arc-minutes):

δ = −0.5 × 0.0175 = −0.00875 radians.

f(x) = tan x, a = π/4: f(a) = 1, f′(a) = sec²(π/4) = 2.

tan(44°30′) ≈ f(a) + δ f′(a) = 1 + 2(−0.00875) = 1 − 0.0175 = **0.9825**.

**Numeric check:**
- linear approximation with the paper's constant: **0.9825000000**
- linear approximation with the exact radian conversion: 0.9825467075
- true tan(44.5°): 0.9826972631

All three agree to three decimal places and option (D) 0.9825 is the exact value the
paper's stated constant produces. Options (A)–(C) are digit permutations of it.
