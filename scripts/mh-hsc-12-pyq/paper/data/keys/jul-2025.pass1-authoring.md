## Working

**(i)** The INVERSE of `A -> B` is `~A -> ~B` (not the converse `B -> A`, and not
the contrapositive `~B -> ~A`). Here `A = p \/ q` and `B = p /\ q`, so by
De Morgan `~A = ~p /\ ~q` and `~B = ~p \/ ~q`, giving
`(~p /\ ~q) -> (~p \/ ~q)`. Option C.

**(ii)** By the sine rule `a/sin A = b/sin B`, so
`sin B = b sin A / a = 3 (2/3) / 2 = 1` exactly. The only angle in a triangle
with sine 1 is `pi/2`. Option A. (The value being exactly 1 rather than
approximately 1 is what makes this unambiguous.)

**(iii)** `AB = B - A`, so `B = A + AB = (1+2, 5-4, 0+7) = (3, 1, 7)`.
Option D. Options A, B and C are permutations of the same three numbers, so the
arithmetic must be done rather than pattern-matched.

**(iv)** Direction vectors `(2,-2,1)` and `(1,2,2)`. Dot product
`2 - 4 + 2 = 0`, so `cos(theta) = 0` and the angle is `pi/2`. Option B.

Note both lines share the base point `(i + 2j + 3k)`. That is printed, and it
changes nothing — the angle between lines depends only on direction. See
`data/ADJUDICATIONS.md`.

**(v)** At `x = 0` the relation `log(x+y) = xy` becomes `log y = 0`, so `y = 1`.
Differentiating implicitly,
`(1 + y')/(x+y) = y + x y'`, and substituting `x=0, y=1` gives
`1 + y' = 1`, so `y' = 0`. sympy's implicit derivative evaluates to `0` at that
point independently. Option D.

**(vi)** `S = 2t^3 - 5t^2 + 4t - 3`, so `S' = 6t^2 - 10t + 4` and
`S'' = 12t - 10`. At `t = 1`, `S'' = 2`. Option A. Option B (8) is `S'(1)`
mis-taken for acceleration is not quite it either — `S'(1) = 0`; 8 is the trap
for differentiating once too few from the wrong term.

**(vii)** Separating,
`sec^2 x / tan x dx + sec^2 y / tan y dy = 0`, which integrates to
`log|tan x| + log|tan y| = c`, i.e. `tan x · tan y = c`. Option C.

Verified independently: implicit differentiation of `tan x · tan y = c` gives
`dy/dx = -sin(2y)/sin(2x)`, and rearranging the printed ODE gives
`dy/dx = -(sec^2 x tan y)/(sec^2 y tan x)`, which simplifies to the same
`-sin(2y)/sin(2x)`. The difference simplifies to exactly `0`.

**(viii)** The density is uniform at `1/5` on `[0,5]`, so
`P(1 < X < 3) = (1/5)(3 - 1) = 2/5`. Option B. Sanity: the interval is two of
the five units of support, and the density is flat, so the answer must be `2/5`.
