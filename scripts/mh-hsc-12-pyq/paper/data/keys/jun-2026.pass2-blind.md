## Q. 1. (i) — C

A = {1,2,3,4,5}. Evaluated each quantifier by exhaustion over A:

| option | statement | truth | witness / counterexample |
|---|---|---|---|
| (a) | exists x: x+3=8 | TRUE | x = 5 |
| (b) | exists x: x+2<9 | TRUE | x = 1 (indeed all of A) |
| (c) | forall x: x+6>=9 | **FALSE** | x = 1 gives 7 < 9; x = 2 gives 8 < 9 |
| (d) | forall x: x+5<=10 | TRUE | max is x=5 giving 10 <= 10 |

Exactly one option is false, so the question is well posed. **(c) / C.**

Note (d) is the near-miss distractor: it is true only because the bound is
non-strict at the largest element (5+5 = 10 <= 10).

## Q. 1. (ii) — B

sin^-1(-1/sqrt2) = -pi/4 (principal branch, in [-pi/2, pi/2]).
sin^-1(sqrt3/2) = pi/3, so 3 sin^-1(sqrt3/2) = pi.
Argument = -pi/4 - pi = -5pi/4.
sin(-5pi/4) = -sin(5pi/4) = -(-1/sqrt2) = +1/sqrt2.

mpmath at 40 dps:

    asin(-1/sqrt2) - 3*asin(sqrt3/2) = -3.926990816987241548...
    that value + 5*pi/4               = -4.59e-41   (i.e. exactly -5pi/4)
    sin(argument)                     =  0.7071067811865475244008443621048490392849
    1/sqrt(2)                         =  0.7071067811865475244008443621048490392848

sympy independently returns sqrt(2)/2. **(b) / B.**

The trap: 3*sin^-1(sqrt3/2) = pi is not itself in the range of arcsin, so a
solver who tries to re-fold it into the principal branch lands elsewhere.
Nothing here needs folding — the argument of the OUTER sine is unrestricted.

## Q. 1. (iii) — C   (this is the stem where "as printed" matters)

Printed: p.(q x r) + q.(p x r) + r.(p x q), with (p,q,r) a right-handed
orthonormal triple, i.e. [p q r] = +1.

- p.(q x r) = [p q r] = +1  (cyclic)
- q.(p x r) = [q p r] = **-1**  (a TRANSPOSITION of [p q r], not a cyclic rotation)
- r.(p x q) = [r p q] = +1  (cyclic)

Sum = 1 - 1 + 1 = **1**.

Numerical check — the standard frame plus three random right-handed orthonormal
frames (QR, with det forced to +1):

    i,j,k frame:   terms 1, -1, 1  -> sum 1
    random det=+1: sum 0.9999999999999993
    random det=+1: sum 1.0
    random det=+1: sum 1.0

**(c) / C.**

**Interpretive flag — deliberate, and the reason this question is worth
attention.** If the middle term were q.(r x p) — the cyclic form, which is what
a tidied version of this identity looks like in most textbooks — every term
would be +1 and the sum would be 3, landing on option **(d)**. The paper as
printed has p x r, and both 3 and 1 are offered as options, so the option set
itself indicates the printed form is the intended discriminator rather than a
typo. I solved it as printed. Reported value: **1**, option C.

## Q. 1. (iv) — C

A(3,4,-1), B(2,-1,3). Direction B - A = (-1, -5, 4).
Line through A: (x-3)/(-1) = (y-4)/(-5) = (z+1)/4.

Substitution test — for each option I computed the three ratios at A and at B;
a point lies on the line iff its three ratios agree.

| option | ratios at A | ratios at B | verdict |
|---|---|---|---|
| (a) (x+3)/1 = (y-4)/5 = (z+1)/-4 | 6, 0, 0 | 5, -1, -1 | A is not even on it |
| (b) (x-3)/-1 = (y-4)/-5 = (z+1)/-4 | 0, 0, 0 | 1, 1, **-1** | fails at B |
| (c) (x-3)/-1 = (y-4)/-5 = (z+1)/4 | 0, 0, 0 | 1, 1, 1 | **both points satisfy** |
| (d) (x-3)/-1 = (y-4)/5 = (z+1)/-4 | 0, 0, 0 | 1, **-1**, -1 | fails at B |

Only (c) passes. **C.** Sign check: z goes -1 -> 3, an increase, so the z
denominator must carry the same sign as the parameter taking x from 3 to 2 —
which is why +4, not -4.

## Q. 1. (v) — A

y = log_x a = (log a)/(log x) by change of base.
dy/dx = log a * d/dx (log x)^-1 = log a * (-(log x)^-2)(1/x)
      = -log a / (x (log x)^2).

sympy: diff(log(a)/log(x), x) simplifies to -log(a)/(x*log(x)**2), and
simplify(dy - optionA) == 0 exactly.

Numeric separation at a = 5, x = 3 (all four options evaluated, so the match is
not an accident of one value):

    true dy/dx = -0.44449212150902706
    (a)        = -0.44449212150902706   <- match
    (b)        =  4.8283137373023015
    (c)        = -0.6826061944859853
    (d)        =  0.20711164485320394

**(a) / A.** Option (d) is the answer to a different question, y = log_a x —
the classic base-confusion distractor.

## Q. 1. (vi) — B

f(x)g(x) = (sin^-1 x) e^(sin^-1 x) / sqrt(1-x^2).
Substitute t = sin^-1 x, dt = dx/sqrt(1-x^2):

    int t e^t dt = e^t (t - 1) + c = e^(sin^-1 x) (sin^-1 x - 1) + c.

Verified by differentiating each candidate antiderivative and comparing with the
integrand (sympy simplify of the difference, plus a numeric point at x = 0.3):

    simplify( d/dx [ e^(asin x)(asin x - 1) ] - integrand ) = 0   (exactly)
    integrand at x=0.3      =  0.43317923090415095
    (b) derivative at x=0.3 =  0.433179230904151    <- match
    (a) derivative at x=0.3 = -0.433179230904151    (sign-flipped)
    (c) derivative at x=0.3 =  3.2765640332319452
    (d) derivative at x=0.3 = -4.707717686265006

**(b) / B.**

## Q. 1. (vii) — B

y = 2x crosses the X-axis at x = 0, and the region runs from x = -1 to x = 4, so
part of it (x in [-1,0]) lies BELOW the axis.

Area = |int_{-1}^{0} 2x dx| + int_{0}^{4} 2x dx = 1 + 16 = **17**.

Geometrically: two triangles — legs 1 and 2 (area 1) below the axis, legs 4 and
8 (area 16) above it.

    signed integral of 2x over [-1,4] = 15.0
    integral of |2x|   over [-1,4]    = 17.0

**(b) / B.**

**Interpretive flag.** Both 15 and 17 are offered, so the option set is baiting
the signed integral. "Area bounded by" is a non-negative quantity, and the
Maharashtra Std XII treatment of area under a curve takes the magnitude of any
sub-region lying below the X-axis, so 17 is the correct reading. A solver who
computes int_{-1}^{4} 2x dx without splitting at the zero gets 15 and lands on
(a). Flagged because it is the one place in this set where an examiner's key
could plausibly differ from the mathematics; the mathematics gives 17.

## Q. 1. (viii) — C

Binomial(n, p): E(X) = np = 6, Var(X) = npq = 4.2.
q = Var/E = 4.2/6 = 0.7, so p = 1 - 0.7 = 0.3, and n = 6/p = 6/0.3 = 20.

sympy solve of {np = 6, np(1-p) = 4.2} returns the single admissible solution
{n: 20, p: 3/10}. Sanity: n = 20 is a positive integer and p = 0.3 lies in
(0,1), so the parameters are legitimate. Check: 20*0.3 = 6 and 20*0.3*0.7 = 4.2.

**(c) / C.** The distractors 22, 24, 26 correspond to no consistent (n, p) pair
for these moments.
