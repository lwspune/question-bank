## Working

**(i)** `tan^{-1}(1/3) + tan^{-1}(1/2) = pi/4` — the same identity that carried
Feb-2026 Q.1(iii). So the value is `cos(pi/4) = 1/sqrt2 = 0.70710678`, confirmed
by direct evaluation. Option C. Option D offers `pi/4` itself, which is the angle
rather than its cosine.

**(ii)** `|a·b| = |a||b||cos t|` and `|a×b| = |a||b||sin t|`, so the condition is
`|cos t| = |sin t|`, i.e. `|tan t| = 1`. On `[0, pi]` that gives `t = pi/4` or
`t = 3pi/4`. Option B. Both must be offered together, which only (B) does.

**(iii)** Direction vectors `(3,2,6)` and `(1,2,2)`: dot product
`3 + 4 + 12 = 19`, norms `7` and `3`, so `cos(theta) = 19/21`. Option D. The
distractors are 17/21, 18/21 and 20/21 — the dot product must be computed, not
estimated.

**(iv)** Perpendicular distance from the origin to `r·n = d` is `|d|/|n|`. Here
`|n| = sqrt(4 + 9 + 1) = sqrt(14)`, so the distance is `5/sqrt(14)`. Option A.

**(v)** From `x = e^{x/y}`, taking logs gives `ln x = x/y`, hence
`y = x/ln x`. Differentiating, `dy/dx = (ln x - 1)/(ln x)^2`.

All four options were substituted with `y = x/ln x` rather than testing only the
expected one:

| option | reduces to | equals dy/dx? |
|---|---|---|
| (A) `1 - y/x` | `1 - 1/ln x` | no |
| (B) `1 + y/x` | `1 + 1/ln x` | no |
| **(C)** `(x-y)/(x log x)` | `(ln x - 1)/(ln x)^2` | **yes** |
| (D) `(x+y)/(x log x)` | `(ln x + 1)/(ln x)^2` | no |

Option C.

**(vi)** `y = c^2 + c/x` gives `dy/dx = -c/x^2`, so `c = -x^2 (dy/dx)`.
Substituting into option A's left-hand side,
`x^4 (dy/dx)^2 - x(dy/dx) - y` simplifies to exactly `0` in sympy. Option A —
and note the differential equation is first-order but SECOND degree, which is
what eliminating a squared constant produces.

**(vii)** `E(X) = np = 10(0.4) = 4` and `Var(X) = npq = 10(0.4)(0.6) = 2.4`.
Option C. Option A offers `4, 0.24`, which is the variance off by a factor of
ten.

**(viii)** `44 deg 30' = 45 deg - 0.5 deg`. Using the conversion GIVEN in the
stem, `0.5 deg = 0.5(0.0175) = 0.00875` radians. With `f(x) = tan x`,
`f(pi/4) = 1` and `f'(pi/4) = sec^2(pi/4) = 2`:

`tan(pi/4 - 0.00875) ~ 1 - 2(0.00875) = 1 - 0.0175 = 0.9825`

Option D. The true value is `0.98269726`, so the linear approximation is in error
by `0.0002` — consistent with a step of under a hundredth of a radian. The stem
supplies its own conversion factor, so `0.0175` is used rather than `pi/180`.
