## Q. 1. (i) — inverse of (p ∨ q) → (p ∧ q)

The inverse of `P → Q` is `~P → ~Q`. With `P = (p ∨ q)`, `Q = (p ∧ q)`:

    ~(p ∨ q) → ~(p ∧ q)   ≡   (~p ∧ ~q) → (~p ∨ ~q)      [De Morgan on both sides]

which is exactly option **(C)**.

Option (A) `(p ∧ q) → (p ∨ q)` is the **converse**, not the inverse.

**Interpretive flag (worth recording).** The inverse and the converse of any
conditional are always logically equivalent to each other, so (A) and (C) have
identical truth tables — both are tautologies here. The exhaustive check:

```
inv: [T, T, T, T]
 A : [T, T, T, T]   <- same truth table (it is the CONVERSE)
 B : [T, T, T, F]
 C : [T, T, T, T]   <- MATCH, and the correct FORM
 D : [T, F, F, T]
```

So the question is only well-posed if "inverse" is read as a **statement
pattern** (a syntactic form), which is how the Maharashtra textbook defines it —
and under that reading (C) is uniquely right. I answer **C**. A candidate who
answered (A) on truth-functional grounds would not be wrong about the logic,
only about what the word "inverse" names. This is a latent defect in the item,
not in the derivation.

## Q. 1. (ii) — ΔABC, a = 2, b = 3, sin A = 2/3

Sine rule `a/sin A = b/sin B`:

    2 / (2/3) = 3 / sin B   ⇒   3 = 3/sin B   ⇒   sin B = 1   ⇒   B = π/2

Sanity check that the triangle exists: A = arcsin(2/3) ≈ 41.81°, B = 90°, so
C ≈ 48.19°, and a/sin A = b/sin B = 3 is consistent. Answer **A**.

## Q. 1. (iii) — terminal point of AB

`AB = B − A`, so `B = A + AB = (1,5,0) + (2,−4,7) = (3,1,7)`.

sympy: `Matrix([[3, 1, 7]])`. Answer **D**. (Note all four options are
permutations of {1,3,7} — the item is testing exactly the add-vs-subtract and
component-order slips.)

## Q. 1. (iv) — angle between the two lines

Direction vectors `d₁ = (2,−2,1)`, `d₂ = (1,2,2)`.

    d₁·d₂ = 2 − 4 + 2 = 0

sympy: `cos = 0`, `angle = pi/2`. Answer **B**. (Both lines also share the same
point (1,2,3), so they genuinely intersect at right angles — the geometry is
consistent, not just the dot product.)

## Q. 1. (v) — log(x + y) = xy, find dy/dx at x = 0

At `x = 0`: `log(y) = 0 ⇒ y = 1` (sympy: the unique solution is `y = 1`).

Differentiating implicitly:

    (1 + y′)/(x + y) = y + x·y′

sympy solves the implicit derivative as

    dy/dx = (1 − xy − y²)/(x² + xy − 1)

and substituting `(x, y) = (0, 1)` gives `0`.

Numerical confirmation — solving `log(x+y) − xy = 0` for y at `x = ±1e−5` and
taking a central difference gives slope `6.7e−11` (i.e. 0). Answer **D**.

**Interpretive choice:** `log` read as the natural log, the Maharashtra
Std XII convention. I tested the base-10 reading too: it gives
`y′(0) = ln 10 ≈ 1.3026` (numeric: `1.30258509518915`), which matches **no**
option — so the natural-log reading is the one the item intends, and this is
self-consistent rather than an assumption I had to make blind.

## Q. 1. (vi) — acceleration at t = 1

    S  = 2t³ − 5t² + 4t − 3
    v  = dS/dt  = 6t² − 10t + 4
    a  = d²S/dt² = 12t − 10        ⇒   a(1) = 2

sympy: `2`. Answer **A**. (For reference, `v(1) = 6 − 10 + 4 = 0`, so none of
the distractors is a velocity-instead-of-acceleration trap; `10` is `|S″(0)|`
and `14` is `S″(2)`.)

## Q. 1. (vii) — sec²x·tan y dx + sec²y·tan x dy = 0

Divide through by `tan x · tan y`:

    (sec²x / tan x) dx + (sec²y / tan y) dy = 0
    d(ln|tan x|) + d(ln|tan y|) = 0
    ln|tan x · tan y| = const     ⇒     tan x · tan y = c

Verification that `F = tan x · tan y` is an integrating-factor-free potential:

    ∂F/∂x = sec²x · tan y     (matches the dx coefficient exactly)
    ∂F/∂y = sec²y · tan x     (matches the dy coefficient exactly)

so the equation is already exact with `F` as its potential — the level curves of
`tan x · tan y` ARE the solutions.

Numerical residual check along `tan x · tan y = 0.5` at `x = 0.4`:
`sec²x·tan y + sec²y·tan x·(dy/dx) = −2.2e−16` (zero).
The same residual for option (A)'s curve `tan x · cot y = c` is `1.993` — not a
solution. Answer **C**.
