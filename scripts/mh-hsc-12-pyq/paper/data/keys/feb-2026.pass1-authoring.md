## Working

**(i)** Contrapositive of \(A \rightarrow B\) is \(\sim B \rightarrow \sim A\).
With \(A = \sim p\), \(B = q\): contrapositive is \(\sim q \rightarrow p\).
Converse of \(X \rightarrow Y\) is \(Y \rightarrow X\), so the converse of that is
\(p \rightarrow \sim q\) — option C. Option B is the contrapositive itself, which
is what you get by stopping one step early.

**(ii)** sympy `Matrix([[2,-4],[3,1]]).adjugate()` -> `[[1, 4], [-3, 2]]`. Option D.

**(iii)** THE TRAP, and it fired live. Numerically \(x = 1/6\) gives
\(\arctan(1/3) + \arctan(1/2) = 0.785398163397 = \pi/4\) to 12 places, but
`simplify(v - pi/4) == 0` returned **False**, and `solve(...)` raised
`NotImplementedError: multiple generators`. Both are the project's standing
warnings verbatim — a non-zero `simplify` is not evidence of inequality, and a
CAS returning nothing is a question, not a verdict. Adjudicated numerically.
Algebraically \(\frac{5x}{1-6x^2} = 1 \Rightarrow 6x^2 + 5x - 1 = 0\), roots
\(1/6\) and \(-1\); \(-1\) is rejected because both arctans are then negative and
the sum is \(-3\pi/4\), not \(+\pi/4\). Option B.

**(iv)** \(\sin\theta = \frac{|\bar{b} \cdot \bar{n}|}{|\bar{b}||\bar{n}|}\) with
\(\bar{b} = \hat{i}+\hat{j}+\hat{k}\), \(\bar{n} = 2\hat{i}-\hat{j}+\hat{k}\):
\(|\bar b \cdot \bar n| = 2\), \(|\bar b| = \sqrt3\), \(|\bar n| = \sqrt6\), so
\(\sin\theta = 2/\sqrt{18} = \sqrt2/3 = 0.4714045\). Option A.

**(v)** \(\frac{d}{dx}\sec(\arctan x) = \frac{x}{\sqrt{x^2+1}}\) (sympy), which at
\(x=1\) is \(1/\sqrt2 = 0.7071068\). Option C.

**(vi)** \(f(2) = 7\), \(f'(x) = 3x^2-3\) so \(f'(2) = 9\), \(dx = -0.01\):
\(f(1.99) \approx 7 + 9(-0.01) = 6.91\). Exact \(f(1.99) = 6.910599\), so the
linear approximation is right and B is the intended answer. Option B.

**(vii)** Substitute \(t = 1/x\), \(dt = -dx/x^2\): the integral is
\(\int_{1/2}^{1} e^t dt = e - e^{1/2} = \sqrt{e}(\sqrt{e}-1)\). sympy gives
`E - exp(1/2)`; mpmath quadrature gives 1.06956055775891708851, and option C
evaluates to 1.069560557759. Option C.

**(viii)** First check it is a density at all: \(\int_{-2}^{4}\frac{x+2}{18}dx = 1\)
and the integrand's minimum on the support is \(0\) at \(x=-2\), so it is
non-negative throughout — a genuine p.d.f.

This matters beyond this question. The sibling compilation carries a corrupted
version of this same stem as \(\frac{2x+1}{18}\), which also integrates to exactly
1 over \((-2,4)\) and so passes the obvious check, yet is negative on part of its
support and is therefore not a density. The printed paper reads \(\frac{x+2}{18}\).
**The printed paper is clean; the compilation is the corrupted copy** — independent
confirmation of an adjudication the project had already made from internal
evidence alone.

\(P(|X|<1) = \int_{-1}^{1}\frac{x+2}{18}dx = \frac{4}{18} = \frac{2}{9}\). Option B.
