# Draft brief: board Chemistry calculations (Maharashtra HSC Class 12, 2026-11-08)

Read first, in full: physics-draft.md (including "Learned on the first
chapters") and the briefs it names. Everything there applies; this brief only
says what is different for Chemistry. Each question gets exactly one of: an
algebra-steps draft, a sketch draft, or a skip.

## Which kind

- **Algebra steps** for every numerical: molarity, molality, mole fraction,
  colligative properties (ΔTb, ΔTf, osmotic pressure, vapour-pressure
  lowering), pH and pOH, Ka, Kb, Ksp and solubility, degree of dissociation,
  ΔH, ΔU, ΔS, ΔG and K, Hess's law sums, cell emf and Nernst, ΔG° = −nFE°,
  conductivity and molar conductivity, Faraday's laws, rate constants,
  half-lives, Arrhenius, unit-cell density, edge length, radius, packing
  efficiency, number of atoms per cell.
- `log10` and `ln` exist in formulas. A line that uses a table value of a
  log (log 2 = 0.3010) is a `calc` on that value as written; when the
  solution rounds an antilog, give `sf`.
- A **sketch** only for a unit cell seen face-on (atoms at corners and face
  centres, the edge a and the diagonal that relates a to r) when the
  solution reasons from that geometry. Never draw molecules, orbitals or
  structures.
- **Skip** (none): reactions and mechanisms, structures, naming, reasons,
  definitions, "write the equation", "explain why", recall MCQs, a
  derivation argued in words, and every organic question without a number.

## Chemistry numbers

- Units in tex as in Physics (`\\text{mol L}^{-1}`, `\\text{J K}^{-1}\\text{mol}^{-1}`).
- R is whatever the solution uses (8.314 J, 0.0821 L atm, 0.08205); F =
  96500 C unless the solution says otherwise. Never swap in a more precise
  constant.
- Powers of ten get `sf`, as in Physics (Ksp = 1.8 × 10⁻¹⁰).

## Output, checks and report

Exactly as physics-draft.md: three files per slice (algebra, sketch, skip with
a `situation` word: reaction, mechanism, structure, naming, definition,
explainWhy, recallMcq, wordDerivation, ...), check-drafts on each, and a
report that quotes every stored text you call a slip EXACTLY as stored.
