chapter: Number System
subtopic: Rational and Irrational Numbers
difficulty: EASY
answer: C
stem:
If a is rational and \(\sqrt{b}\) is irrational, then \(a + \sqrt{b}\) is:
A: A rational number
B: A natural number
C: An irrational number
D: An integer
solution:
If \(a + \sqrt{b}\) were rational, then \(\sqrt{b} = (a + \sqrt{b}) - a\) would be a difference of two rationals, which is rational. That contradicts \(\sqrt{b}\) being irrational.

So the sum of a rational and an irrational number is an irrational number.
