If x is a whole number, then \(8^x\) ends with an even digit, except for which value of x?
A: 0
B: 2
C: 6
D: 4
solution:

subtopic: Fractions and Rational Numbers
difficulty: MODERATE
answer: D
stem:
In each of the following, state whether the statements are true (T) or false (F).
i. If \(\frac{x}{y}\) is a rational number, then y is always a whole number.
ii. If \(\frac{p}{q}\) is a rational number, then p cannot be equal to zero.
iii. If \(\frac{r}{s}\) is a rational number, then s cannot be equal to zero.
A: TFF
B: FTF
C: TFT
D: FFT
solution:
i. False: the denominator of a rational number can be a negative integer, for example \(\frac{1}{-2}\), and \(-2\) is not a whole number.

ii. False: the numerator can be zero, since \(\frac{0}{5} = 0\) is rational.

iii. True: a denominator of zero is not allowed.

So the answer is FFT.

stem:
The graph of a pair of linear equations \(a_1x + b_1y = c_1\) and \(a_2x + b_2y = c_2\) in two variables x and y represents parallel lines, if
A: \(\frac{a_1}{a_2} \ne \frac{b_1}{b_2}\)
B: \(\frac{a_1}{a_2} = \frac{b_1}{b_2} \ne \frac{c_1}{c_2}\)

The printed "some pressure" is evidently a misprint for "same pressure"; read either way it is the only true statement.
