chapter: Arithmetic Reasoning
subtopic: Equations from Word Problems
difficulty: MODERATE
answer: A
stem:
If P + Q = 2R and R + S = 2P, then:
A: P + R = Q + S
B: P + R = 2S
C: P + S = Q + R
D: P + R = 2Q
solution:
Add the two equations: \(P + Q + R + S = 2R + 2P\).

Subtract \(P + R\) from both sides: \(Q + S = P + R\), which is option A.

Check with numbers: take \(P = 2, R = 3\), so \(Q = 4\) and \(S = 1\). Then \(P + R = 5 = Q + S\), while \(2S = 2\), \(P + S = 3 \ne Q + R = 7\) and \(2Q = 8\).
