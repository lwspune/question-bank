difficulty: EASY

stem:
Find the value of Y, if \(X - 2Y + 2Z = 16\), \(X - Y + Z = 9\) and \(2X - 3Y - Z = 9\).
A: \(2\)
B: \(-3\)
C: \(-4\)
D: \(4\)
solution:
Subtract the second equation from the first: \(-Y + Z = 7\), so \(Z = Y + 7\).

Put this in the second equation: \(X - Y + Y + 7 = 9\), so \(X = 2\).

Third equation: \(4 - 3Y - (Y + 7) = 9\), so \(-4Y = 12\) and \(Y = -3\) (then \(Z = 4\)).

Check in the first equation: \(2 + 6 + 8 = 16\).
