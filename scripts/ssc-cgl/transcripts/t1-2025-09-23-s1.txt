subtopic: Inequality Chains
difficulty: EASY
answer: C
stem:
Read the given statement and conclusions carefully. Decide which of the given conclusions is/are definitely true from the statement.

Statement: \(P = Q \ge S > T = R \ge U > V\)
Conclusion I: \(Q \ge U\)
Conclusion II: \(T = U\)
A: Both Conclusion I and Conclusion II are True.
B: Both Conclusion I and Conclusion II are False.
C: Only Conclusion I is True.
D: Only Conclusion II is True.
solution:
\(Q \ge S > T = R \ge U\) gives \(Q > U\), so \(Q \ge U\) is definitely true: I is true.

\(T = R \ge U\) gives only \(T \ge U\); T may be greater than U, so \(T = U\) is not definite: II is false.

Only I is true.

subtopic: Sound Behaviours — Reflection, Echo, Reverberation, Beats
difficulty: MODERATE
answer: C
stem:
What happens to the perceived frequency when both the source and the listener move with the same speed in the same direction?
A: It increases
B: It decreases
C: It remains unchanged
D: It fluctuates rapidly
solution:
By the Doppler formula \(f' = f \frac{v + v_o}{v + v_s}\) with signs for motion along the line. If source and listener move together with the same speed \(u\) in the same direction, the factors cancel: \(f' = f \frac{v - u}{v - u} = f\).

There is no relative motion between them, so the frequency heard is unchanged.
