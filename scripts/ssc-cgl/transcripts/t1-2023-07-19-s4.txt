In a certain code language, “ENVOY” is written as “DMUNX” and “CHECK” is written as “BGDBJ”. How will “ANGLE” be written in that language?
A: ZNDID
B: YLDJD
C: YNEJC
D: ZMFKD
solution:

stem:
In a certain code language, 'TURNIP' is coded as VNRUWU and 'DAIKON' is coded as TTOLCE. How will 'RADISH' be coded in the same language?
A: NXMGCS
B: NXNHCS
C: MXNHCS
D: CYMGDP
solution:
Write the word backwards, then move the letters forward by 6, 5, 4, 3, 2, 1.

TURNIP backwards is PINRUT: P+6 = V, I+5 = N, N+4 = R, R+3 = U, U+2 = W, T+1 = U, giving VNRUWU. DAIKON backwards is NOKIAD, giving TTOLCE in the same way.

RADISH backwards is HSIDAR: H+6 = N, S+5 = X, I+4 = M, D+3 = G, A+2 = C, R+1 = S, giving NXMGCS.

The second number in the given number pairs is obtained by performing certain mathematical operation(s) on the first number. The same operation(s) are followed in all the number pairs, EXCEPT one. Find that odd number pair.
A: (125, 91)
B: (64, 61)
C: (27, 37)
D: (8, 20)
solution:
