note: Judgement on "maintaining an open session": RRB keys Sleep, which keeps the session live in RAM on very little power; Hibernate saves it to disk and switches the machine off, so the session is stored, not open. Key adopted.
stem:
Which power mode uses the least electricity while maintaining an open session?
A: Sleep
B: Standby
C: Hibernate
D: Active mode
solution:
Sleep keeps the open session (programs and documents) live in RAM and powers down almost everything else, so it uses very little electricity and the work resumes in seconds.

Hibernate saves the session to the hard disk and switches the computer off: it uses even less power, but the session is stored rather than kept open. Active mode uses full power.
